# 技能创建器

帮助用户创建新的技能文件。

## 技能模板

```markdown
---
name: 技能名（英文，小写，连字符分隔）
description: 简短描述，一句话说明技能用途
---

# 技能标题

详细说明技能的能力和使用方式。
```

## 使用方式

1. 询问用户：技能名称、用途、能力
2. 根据用户描述，生成 SKILL.md 内容
3. 使用 Write 工具写入 `.claude/skills/技能名/SKILL.md`
4. 技能文件保存后，无需重启，下次对话自动生效
5. 完成后告诉用户技能已创建，可以用 `/技能名` 调用

## 注意事项

- skill 名称用英文小写 + 连字符，如 `ops-knowledge`、`code-review`
- description 要简洁准确，帮助模型判断何时使用
- 正文要清晰描述技能的能力边界
