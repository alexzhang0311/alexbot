# 代码审查

对代码进行全面审查，检查代码质量、安全性、性能和可维护性。

## 审查维度

1. **正确性** — 逻辑是否正确，边界条件处理
2. **安全性** — SQL 注入、XSS、敏感信息泄露、权限校验
3. **性能** — 算法复杂度、N+1 查询、内存泄漏、不必要的循环
4. **可读性** — 命名规范、注释质量、代码结构
5. **可维护性** — 模块化、DRY 原则、SOLID 原则
6. **错误处理** — 异常捕获、回滚、用户提示

## 使用方式

- 用户提供代码或文件路径 → Read 工具读取
- 逐文件审查，输出问题列表
- 每个问题标注严重程度：🔴严重 🟡警告 🔵建议

## 输出格式

```
## 代码审查报告

### 文件: xxx.py
| 行号 | 严重度 | 问题 | 建议 |
|------|--------|------|------|
| 42   | 🔴严重  | SQL 注入 | 使用参数化查询 |
| 58   | 🟡警告  | 未处理异常 | 添加 try/except |
```
