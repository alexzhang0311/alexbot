# 常见问答 FAQ

## 已知问题与答案

| 问题 | 答案 |
|------|------|
| 怎么改密码 | 在设置页面点击"账户安全" → "修改密码" |
| 怎么联系客服 | 发邮件到 support@company.com 或拨打 400-xxx-xxxx |
| 怎么升级会员 | 进入"会员中心"选择套餐进行升级 |

## 使用方式

当用户询问 FAQ 时，直接使用上表中的答案回复。如果问题不在表中，诚实告知并建议联系客服。
